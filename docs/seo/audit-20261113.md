# pilk.ai technical SEO audit, 13 Nov 2026

Baseline: `origin/main` at `5d0a6c2`, which is what https://pilk.ai served on
13 Nov 2026 (checked with curl: same titles, canonicals and JSON-LD). Fixes are
on branch `claude/seo-foundation-20261113`. Nothing here was deployed by this
lane; the owner runs the deploy kit.

How it was checked:

- `npm ci && npm run build`, then `node scripts/seo-check.mjs` over every HTML
  route in `out/` (the checker is new in this branch and fails on errors)
- curl against the live site for status codes, redirects, robots.txt and the
  sitemap
- `wrangler pages dev out` plus the existing Playwright suite, and screenshots
  of the new pages at 1440px and 390px

## Findings and status

Severity: P0 = can hurt the whole domain, P1 = clear ranking or crawl loss,
P2 = worth fixing, P3 = polish.

### P0

1. **Fake review markup on indexable demo sites.** `/template-previews/*` (131
   HTML files) served `robots: index, follow` with `FinancialService` markup for
   fictional lenders. Five carried `AggregateRating` built from sample copy
   (for example 4.9 from 612 reviews) next to placeholder `NMLS #123456`.
   Rating markup for reviews that don't exist is against Google's structured
   data policy and can bring a manual action for the whole domain.
   **Fixed:** `public/_headers` sends `X-Robots-Tag: noindex, follow` for
   `/template-previews/*`; ratings stripped from the five files;
   `scripts/pilk-seo-inject.mjs` no longer generates ratings and writes
   noindex if it is ever re-run.

### P1

2. **Sitemap pointed at redirects.** `next.config.mjs` exports with
   `trailingSlash: true`, so Cloudflare serves `/work/` and 308-redirects
   `/work`. All 46 sitemap URLs used the no-slash form (home was
   `https://pilk.ai` with no slash). Canonical tags were already correct
   (Next adds the slash), so the sitemap disagreed with every canonical.
   **Fixed:** every URL the site hands out goes through `absoluteUrl()` in
   `src/lib/metadata.ts`.
3. **Sitemap incomplete and undated.** `/apps`, `/mortgage` and
   `/own-vs-rent` were never listed; `lastmod` was `new Date()` on every URL, so
   it carried no signal. **Fixed:** route list in `src/app/sitemap.ts` covers
   all 57 indexable pages; `lastmod` comes from `git log` on each page's own
   source files (`src/lib/lastmod.ts`), build time for uncommitted files.
4. **No pages for most services.** The Google Business Profile lists AI
   consulting, custom apps, AI automation and chatbots, websites, Meta ads,
   social media automation, lead funnels and Skool community growth. Only apps
   (/apps) and real-estate/mortgage websites had pages. **Fixed:** `/services/`
   hub plus seven service pages and `/st-petersburg-tampa-bay/` (list below).
5. **Thin and duplicate utility pages indexable.** 23 `/start/<template>/`
   order forms, three checkout pages, `/inquiry`, the placeholder `/lab`
   ("in development"), the expired `/fourth-of-july` sale and the listing demo
   (fictional "Meridian Estates") were all indexable. **Fixed:** `noindex,
   follow` through `buildMetadata({ noindex: true })`; none are in the sitemap.
   Robots Disallow was deliberately not used, because a disallowed URL can
   still be indexed from links and its noindex would never be read.
6. **Entity data inconsistent.** Two separate JSON-LD nodes named "Pilk.ai
   Media", `areaServed: "St. Petersburg · Tampa Bay · Remote"` as a string, no
   legal name, phone, sameAs or founder, and the logo was the white-text PNG.
   **Fixed:** see Schema below.

### P2

7. **Descriptions too long or too short.** 8 over 155 characters (mortgage was
   272), 26 indexable pages under 70. **Fixed:** rewritten; `buildMetadata`
   also clamps anything over 155 at a word boundary as a safety net.
8. **Weak titles.** Home title was the tagline only ("Pilk.ai Media — Websites
   people remember."), with no service or place. Work pages were just the
   project name; template titles repeated "Template". **Fixed:** home is
   "Pilk.ai — Websites, Apps & AI Consulting in St. Petersburg"; every title is
   unique and 60 characters or less with a "· Pilk.ai" suffix.
9. **Share image.** Every page shared `/pilk-logo-dark.png`, a 6250x6250 PNG
   whose white lettering disappears on light backgrounds. **Fixed:**
   `public/og/pilk-ai-og.jpg` (1200x630, 63 KB); work and template pages use
   their screenshots where the file exists.
10. **Dead footer links.** Instagram, LinkedIn and X linked to `#` on every
    page. **Fixed:** removed; footer links real profiles (Clutch, Crunchbase,
    Dribbble, Medium) and every service page.
11. **404 page.** Copied the home page title and a canonical to `/`. Cloudflare
    already returns a real 404 status. **Fixed:** own title, noindex, no
    canonical, links to services.
12. **Internal links to redirects.** Template preview links used
    `/template-previews/<slug>/index.html`, which 308s to the folder URL.
    **Fixed** in `src/content/templates.ts`.
13. **Oversized images.** `/work/*.jpg` were 2880x1800 (up to 491 KB) but
    display at most about 1400px wide. **Fixed:** resized to 1600x1000,
    2.5 MB down to 1.3 MB.

### P3 and recommendations (not changed here)

14. **Hero photos are CSS backgrounds.** `/real-estate` and `/mortgage` use
    `hero-estate.jpg` (285 KB) and `hero-warm-home.jpg` (353 KB) as the likely
    LCP element, loaded through CSS so the browser finds them late. A WebP or
    AVIF version through `image-set()` plus a `<link rel="preload">` would cut
    LCP. Re-saving the JPEGs only saves 20 to 25%, so it wasn't worth the
    generational loss.
15. **First-visit preloader.** `Preloader` covers the page for about 2.6 s on
    the first visit of each session. It is a design choice, but it can delay
    LCP and INP on first visits. Worth measuring in Search Console's Core Web
    Vitals report once it has data.
16. **WebGL canvas on every route.** Loaded lazily and degraded by device
    capability, which is good. Shared first-load JS is 106 KB; the home page
    is 179 KB. No change needed now.
17. **/checkout has no h1.** It is noindex now, so it doesn't matter for search,
    only for accessibility.
18. **Alt text.** No `<img>` without alt on any route, before or after.

## Content accuracy notes for the owner

These are claims already on the site that this lane did not change:

- **Privacy and Terms are placeholders.** Both pages show "Placeholder policy —
  replace with your reviewed legal copy before launch" on the live site, and
  name "Pilk.ai Media" rather than Pilk Consulting LLC.
- **Timelines disagree.** The FAQ says templates launch in 1 to 3 weeks, the
  process page says seven days, mortgage templates say 14 days. The new
  websites page follows the process page's wording (seven days for qualified
  template projects after content and approvals).
- **Mortgage page dashboard numbers.** The tracking mockup shows "2,481
  visitors, 143 leads, $12 cost per lead". If those are illustrative, label
  them as an example.
- **Competitor pricing.** `/own-vs-rent` says Placester costs $59 to $599 a
  month. Worth re-checking that it is still current.
- **Listing experience page** says "Two scroll-driven experiences" but only one
  exists. The page is noindex now.
- **App store links.** `src/content/apps.ts` still has `"#"` for the Watchmen
  and FamLink store links (they are not rendered as links today).

## Schema now on the site

Every page carries one `@graph` from `siteGraph()` in `src/lib/metadata.ts`:

- `ProfessionalService` `#organization`: name "Pilk.ai", legalName "Pilk
  Consulting LLC", alternateName "Pilk.ai Media", url, logo
  (`/brand/pilk-ai-logo-512.png`, dark text on white), email Aaron@pilk.ai,
  telephone +1-704-877-3511, `PostalAddress` with city, state and country only,
  areaServed St. Petersburg (City in Florida) and Tampa Bay, Florida (Place),
  sameAs the seven real profiles, founder, knowsAbout, and an `OfferCatalog`
  referencing each Service by `@id`
- `Person` `#founder`: Aaron Pilkington, Founder
- `WebSite` `#website`: name "Pilk.ai", alternateName "Pilk.ai Media",
  publisher = the organization

Page-level nodes reference the organization by `@id`:

- service pages: `Service` (provider, areaServed, serviceType),
  `BreadcrumbList`, `FAQPage` matching the visible FAQ
- `/apps/`: `Service` + `BreadcrumbList`; `/mortgage/`: `Service` with an
  `Offer` whose `priceSpecification.minPrice` is the starting figure (500 USD;
  no fixed price, no checkout since the quote-only release) + `BreadcrumbList`
- `/services/`: `BreadcrumbList` + `ItemList`
- `/st-petersburg-tampa-bay/`: `BreadcrumbList` + `FAQPage`
- `/real-estate/`: `FAQPage` (the shared FAQ, marked up once) + `BreadcrumbList`
- every other inner page: `BreadcrumbList`

No street address, no review or rating markup anywhere. Every block is parsed
by `scripts/seo-check.mjs` on each run.

## Crawl files

- `/sitemap.xml`: 57 URLs, trailing slash, git-dated lastmod. Deploy from a
  full clone: in a shallow clone, files untouched within the fetched depth get
  the boundary commit's date.
- `/robots.txt` (the site's part): `Allow: /`, `Disallow: /api/`, `Sitemap`.
  Cloudflare's managed block that blocks AI crawlers is prepended at the edge
  and is configured in the dashboard, not here.
- `/llms.txt`: business summary and key pages.
- IndexNow: key file `public/8b02a91ba42fb9ff1b2a5eed727a7ce8.txt`;
  `node scripts/indexnow-submit.mjs --all` (add `--dry-run` to preview). It
  refuses to send until the live key file serves the key.
